# rdm-dl.github.io

Publishes the RDM website at **https://rdm-dl.github.io**.

The pages themselves live in the [`docs/` folder of rdm-dl/rdm](https://github.com/rdm-dl/rdm/tree/main/docs). Edit them there; this repo picks up changes every 6 hours, or right away from **Actions → Publish website → Run workflow**.
